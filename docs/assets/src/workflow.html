The route

One flow verb, idea → merged PR. Each mode is a reference file the session reads before acting.

T0 → aligned

align

  • Interview by the grilling skill
  • Terms and decisions land in CONTEXT.md and ADRs as they resolve
  • Ends when a T1 can be published
/rumo <idea>
T1

ticket

  • A tracer-bullet GitHub issue
  • Native sub-issues and blocking links
  • Labels from the repo's own vocabulary
/rumo ticket
T2 · worktree

build

  • Planner writes typed steps to .rumo/plan.md
  • Builders run in waves, ≤ 5 at once
  • Each step accepted by command, not by claim
  • Stops only on a critical question
/rumo build #N
gate

review

  • Tier by diff size and risk
  • bugs ∥ standards ∥ spec (+ security)
  • Proofs replayed before any fix
  • Stamp tied to HEAD
review
PR

ship

  • PR closes its issue
  • Assumptions copied into the PR body
  • Open minors go to one follow-up issue
NEXT: clear
loop

learn

  • Revise, escalate, replan and findings logged as events
  • Repeats become rules in agents, skills, hooks
